# Patch — патч для игроков (канал alpha) и лаунчер (канал launcher)

| Батник | Что делает |
|---|---|
| `0_Patch_All.bat` | всё подряд: обработка Inbox (если не пуст) → новая версия → выгрузка |
| `1_Process_Client.bat` | обработать клиент из `Inbox\`: готовая EAC-сборка — проверка; голая сборка UAT — EAC-обработка (Astory.exe, Settings.json, каталог целостности, проверка утечек и шифрования) |
| `2_Make_Patch.bat` | новая версия в `Releases`: нарезка, подпись Ed25519, глубокая проверка. Версию вводите вручную |
| `3_Verify.bat` | повторная глубокая проверка хранилища выпусков |
| `4_Upload.bat` | выгрузка канала alpha на `@@ASTORY_UPDATE_HOST@@` (SFTP), без подтверждения |
| `5_Launcher_Release.bat` | выпуск лаунчера из `AstoryClient\Launcher\dist` и его выгрузка |
| `6_Resign.bat` | продлить срок подписи канала без новой версии |
| `Status.bat` | текущие версии каналов |
| `Keys_Status.bat`, `Keys_Backup.bat` | состояние ключей выпуска; копия закрытых ключей под пароль |

**Откуда берётся клиент для патча:** если в `Inbox\` что-то лежит — оттуда; если пусто — последняя релизная сборка (`Build\EAC\latest.json`).

**Формат версии:** `alpha-1.0.1-10.2026` (игра), `launcher-1.0.1-10.2026` (лаунчер).

На сервере хранятся текущая и прошлая версия; все выпуски — в `Releases`. Журналы — `Logs\`.
