# GAME — что ставится игроку вместе с лаунчером

Папка собирается батником `Build\5_Collect_GAME.bat` и целиком пересоздаётся при каждом запуске (руками не править).

| Путь | Откуда | Зачем |
|---|---|---|
| `Launcher\` | `Launcher\dist` | лаунчер `AsdaLauncher.exe` и лицензии его библиотек |
| `Redist\vc_redist.x64.exe` | движок UE 5.8, `Engine\Extras\Redist\en-us` | рантайм Visual C++ 2015–2022 x64: нужен лаунчеру и игре |
| `Redist\EasyAntiCheat\` | тулкит EAC 2.3.0 из EOS SDK | установщик службы Easy Anti-Cheat и его лицензии |
| `Legal\EULA.txt` | `Tools\data\legal\EULA_EN.txt` | лицензионное соглашение (требование EOS) |
| `manifest.json` | — | состав, размеры, md5, версия лаунчера, время сборки |

Саму игру сюда не кладём: лаунчер скачивает её в `<папка установки>\Game` и обновляет сам.
Перед сборкой GAME обновите лаунчер, если менялся его код: `Build\4_Launcher_Build.bat`.
