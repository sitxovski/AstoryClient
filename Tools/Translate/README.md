# TRANSLATE — русификация клиента из «Фантазиума» (2012)

Дата: 2026-07-27. Клиенты: `orig` = `@@ASTORY_DEV_ROOT@@\Donors\AsdaChroniclesInterlude_MINE`,
`fanta` = `@@ASTORY_DEV_ROOT@@\Donors\Fantazium` (полностью русский, 2012).

## Что сделано

1. **Распаковка** всех 34 игровых архивов (`b**z` = ZIP) обоих клиентов в
   `textures_*`, `models_*`, `motions_*`, `tables_*`, `scripts_*` (структура каталогов
   повторяет клиент).
2. **Слияние текста строго по ID**: `tools/merge_translate.py` берёт текстовые поля из
   Фантазиума и пишет их в записи MINE с тем же ID. Числовые/ресурсные поля (коды,
   цены, имена мешей/иконок/эффектов) НЕ трогаются — меняются только байты строковых полей.
   Результат в `out_client/`.
3. **Применение** в клиент: `tools/apply_translate.py` (репак `Bin.bbz` + копирование,
   бэкапы `*.translate_bak`).
4. **Отчёты** — `reports/`.

## Ключевые факты формата (проверены в этой сессии)

* MD5-префикс записи = **чистый** `MD5(rec[16:stride])` без соли → при правке строки
  MD5 пересчитывается, иначе клиент пишет `«itemlist.bin md5 err»` и отказывает в загрузке.
* Строки шифрованных таблиц: `хранимый = реальный + 1` по байту (обратно `-1`).
* `system\error list.bin`: у MINE — бинарный (u32 count, 256 Б/запись, шифр `байт-100`,
  затем параллельный массив ID). У Фантазиума — **текстовый** `«ID текст\r\n»` в CP1251.
  Массив ID при слиянии не менялся ни на байт.
* Тексты Фантазиума заканчиваются маркером `~` — один хвостовой снимается.
* `item_tooltip.bin` Фантазиума — легаси-вариант: stride 204 (без MD5-префикса) и без шифра.
  Скрипт распознаёт оба варианта.
* `SNQInfo.Bin`: ключ = `u16@0` (i32 захватывал байты имени).
* `new_item_list.bin` (только у Фантазиума) — **Big5/китайская** таблица, не русская: не используется.

## Защита от деградации

Замена выполняется всегда, когда у Фантазиума есть текст по этому ID — **включая случаи,
когда в MINE уже русский**, как и требовалось. Единственное исключение: если строка
Фантазиума по этому ID **корейская или пустая**, а в MINE — русская/английская, замена
пропускается и попадает в отчёт с пометкой `[FANTA-ХУЖЕ]` / `[FANTA-ПУСТО]`. Без этого
фильтра в клиент затекало ~1000 корейских строк вместо готового текста.

## Откат

Каждый изменённый файл клиента имеет рядом `<имя>.translate_bak` (первый бэкап не
перезаписывается при повторных прогонах). Откат = переименовать бэкапы обратно.

## Повторный прогон

